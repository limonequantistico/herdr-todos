# Commit convention

[Conventional Commits](https://www.conventionalcommits.org/): `<type>: <summary>`, types `feat`, `fix`, `docs`, `refactor`, `chore`, `style`, `test`, `perf`, `build`, `ci`; breaking changes marked with `!` or a `BREAKING CHANGE:` line.

Chosen 2026-10-03 as the default for a new repository (no history to follow yet).
